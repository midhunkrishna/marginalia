marginalia Blocked ⚠

Marginalia can't run on this site

You used the Ask about … menu there, but nothing answered: Marginalia's script never started on that page. Your browser, or a policy on it, is blocking the extension there. Marginalia can't tell which, so here are the usual causes, easiest fix first.

1. Reload the tab

A tab that was already open when Marginalia was installed, updated or re-enabled doesn't get the extension until it reloads. Reload this site, then try again.

2. Check Site access

If Site access is set to On click (or the site isn't allowed), the extension stays off until you grant it.

  • Chrome / Edge: open chrome://extensions (Edge: edge://extensions), choose Marginalia → Details → Site access → On all sites, or On specific sites with this site added.
  • Firefox: open about:addons → Marginalia → Permissions, and allow access to your data for this site. If the Permissions tab lists nothing to toggle, see the next step.
3. Work or school profile? Ask your admin

Managed browsers can block extensions on chosen sites. The install goes through, but the extension never starts there. This can't be changed from inside the extension.

  • Chrome / Edge: open chrome://policy (Edge: edge://policy) and look for ExtensionSettings containing runtime_blocked_hosts, or a policy that mentions this site or its parent domain. If it's there, ask IT to remove the site from the block list for Marginalia.
  • Firefox: open about:policies and look for an ExtensionSettings entry that restricts Marginalia (marginalia@midhunkrishna.github.io), or for restricted quarantinedDomains. Ask IT to allow it for this site.
